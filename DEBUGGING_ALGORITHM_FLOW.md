# 🔧 Guía Completa de Debugging - Sistema de Algoritmos TeamLens\n\n## 🎯 **PROBLEMA REPORTADO**\n\nEl usuario reporta que al hacer clic en \"Crear Grupos\" en el frontend:\n- ✅ Todos los estudiantes han completado BELBIN\n- ✅ Todos los estudiantes están activos\n- ✅ Las restricciones están configuradas\n- ❌ **El botón no responde - No hay feedback visual**\n\n## 🛠️ **HERRAMIENTAS DE DEBUGGING IMPLEMENTADAS**\n\n### 1. **Endpoint de Debugging Completo**\n```http\nGET /activities/:id/debug\n```\n**Propósito:** Analiza el estado completo de una actividad\n**Retorna:** Información detallada sobre estudiantes, BELBIN, configuración, validaciones\n\n### 2. **Endpoint de Testing Directo**\n```http\nPOST /activities/:id/test-create-groups\n```\n**Propósito:** Simula exactamente el botón \"Crear Grupos\" del frontend\n**Retorna:** Resultado paso a paso del proceso completo\n\n### 3. **Script de Testing Automatizado**\n```bash\nnode test-algorithm-flow.js\n```\n**Propósito:** Testing completo end-to-end del sistema de algoritmos\n\n### 4. **Endpoint Principal Mejorado**\n```http\nPOST /activities/:id/algorithm/execute\n```\n**Mejoras:** Logging detallado, validaciones completas, mejor manejo de errores\n\n## 🔍 **PROCESO DE DEBUGGING PASO A PASO**\n\n### **PASO 1: Verificar Estado del Sistema**\n\n#### 1.1 Verificar que el backend esté corriendo\n```bash\n# Verificar salud del servidor\ncurl http://localhost:3000/health\n# Debe responder: \"development\"\n```\n\n#### 1.2 Obtener información completa de debugging\n```bash\n# Reemplaza ACTIVITY_ID con tu ID real\ncurl -X GET \"http://localhost:3000/activities/ACTIVITY_ID/debug\" \\\n  -H \"Cookie: session=TU_SESSION_COOKIE\"\n```\n\n**Analizar la respuesta:**\n- `debug.students.completionPercentage` debe ser 100%\n- `debug.algorithmConfig.hasValidConfig` debe ser true\n- `debug.validation.isValid` debe ser true\n- `debug.algorithmFile.canGenerate` debe ser true\n\n### **PASO 2: Testing Directo (Bypass Frontend)**\n\n#### 2.1 Usar el endpoint de testing directo\n```bash\n# Simula exactamente el comportamiento del frontend\ncurl -X POST \"http://localhost:3000/activities/ACTIVITY_ID/test-create-groups\" \\\n  -H \"Cookie: session=TU_SESSION_COOKIE\" \\\n  -H \"Content-Type: application/json\"\n```\n\n**Este endpoint:**\n- ✅ Verifica la actividad existe\n- ✅ Verifica configuración del algoritmo\n- ✅ Verifica completitud BELBIN con detalles\n- ✅ Genera/verifica archivo JSON\n- ✅ Ejecuta el algoritmo\n- ✅ Retorna resultado paso a paso\n\n### **PASO 3: Verificar Logs del Servidor**\n\nBuscar en la consola del servidor mensajes como:\n```\n🚀 [AlgorithmExecute] INICIANDO EJECUCIÓN DE ALGORITMO\n🔍 [AlgorithmExecute] Paso 1: Validando actividad...\n✅ [AlgorithmExecute] Actividad validada\n```\n\n### **PASO 4: Verificar Problemas Comunes**\n\n#### 4.1 **Problema: Configuración Faltante**\n**Síntoma:** `\"Algorithm is not configured\"`\n**Solución:**\n```bash\n# Configurar algoritmo\ncurl -X PUT \"http://localhost:3000/activities/ACTIVITY_ID/algorithm/config\" \\\n  -H \"Cookie: session=TU_SESSION_COOKIE\" \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"teamSize\": 3,\n    \"minTeams\": 1,\n    \"maxTeams\": 5,\n    \"exclusions\": [],\n    \"inclusions\": []\n  }'\n```\n\n#### 4.2 **Problema: Estudiantes sin BELBIN**\n**Síntoma:** `\"not all students have completed BELBIN test\"`\n**Verificación:**\n```bash\n# Obtener estado detallado de cuestionarios\ncurl \"http://localhost:3000/activities/ACTIVITY_ID/students/questionnaires-status\" \\\n  -H \"Cookie: session=TU_SESSION_COOKIE\"\n```\n\n#### 4.3 **Problema: Worker no se ejecuta**\n**Síntoma:** Estado se queda en 'running' pero no progresa\n**Verificación:**\nBuscar en logs:\n```\n👷 [AlgorithmWorker] Iniciando worker para actividad\n📨 [AlgorithmWorker] Mensaje recibido del worker\n```\n\n#### 4.4 **Problema: Archivo JSON no se genera**\n**Síntoma:** `\"Algorithm JSON file not found\"`\n**Verificación:**\n```bash\n# Verificar directorio exists\nls pyteamformation/instances/\n\n# Buscar archivos de la actividad\nls pyteamformation/instances/activity_*\n```\n\n### **PASO 5: Testing Automatizado**\n\n#### 5.1 Listar actividades disponibles\n```bash\nnode test-algorithm-flow.js --list\n```\n\n#### 5.2 Ejecutar test completo\n```bash\n# Editar test-algorithm-flow.js:\n# 1. Cambiar TEST_ACTIVITY_ID\n# 2. Actualizar cookie de sesión\n\nnode test-algorithm-flow.js\n```\n\n## 🎯 **DIAGNÓSTICOS COMUNES**\n\n### **Problema A: Frontend no llama al backend**\n**Síntomas:**\n- No aparecen logs en el servidor\n- Botón no responde\n\n**Verificación:**\n1. Verificar Network tab en DevTools del navegador\n2. Buscar errores de CORS\n3. Verificar endpoints llamados por el frontend\n\n**Solución:**\n- Usar endpoint de testing directo para verificar que backend funciona\n- Revisar código del frontend\n\n### **Problema B: Backend falla silenciosamente**\n**Síntomas:**\n- Logs aparecen pero se cortan\n- Estado se actualiza pero proceso no continúa\n\n**Verificación:**\n1. Usar endpoint de debugging para ver estado completo\n2. Verificar logs del worker\n3. Verificar que Python esté disponible\n\n**Solución:**\n```bash\n# Verificar Python\npython --version\ncd pyteamformation\npython equipos_lola.py --help\n```\n\n### **Problema C: Validaciones fallan**\n**Síntomas:**\n- Error 400 con mensaje específico\n- Validación isValid = false\n\n**Verificación:**\n1. Usar endpoint de validación:\n```bash\ncurl \"http://localhost:3000/activities/ACTIVITY_ID/algorithm/validation\"\n```\n\n2. Revisar errores específicos en la respuesta\n\n### **Problema D: Worker falla**\n**Síntomas:**\n- Estado 'running' pero no progresa\n- Logs de worker muestran errores\n\n**Verificación:**\n1. Verificar archivo `algorithm-req-worker.js`\n2. Verificar que archivo JSON existe\n3. Ejecutar Python manualmente:\n```bash\ncd pyteamformation\npython equipos_lola.py instances/activity_ACTIVITY_ID_belbin.json\n```\n\n## 🚀 **FLUJO DE RESOLUCIÓN RECOMENDADO**\n\n### **Para el usuario con el problema:**\n\n1. **Obtener información básica:**\n   ```bash\n   # Obtener ID de actividad y session cookie del navegador\n   # Usar DevTools → Application → Cookies\n   ```\n\n2. **Ejecutar debugging completo:**\n   ```bash\n   curl -X GET \"http://localhost:3000/activities/TU_ACTIVITY_ID/debug\" \\\n     -H \"Cookie: session=TU_SESSION_COOKIE\"\n   ```\n\n3. **Si debugging muestra todo OK, ejecutar test directo:**\n   ```bash\n   curl -X POST \"http://localhost:3000/activities/TU_ACTIVITY_ID/test-create-groups\" \\\n     -H \"Cookie: session=TU_SESSION_COOKIE\" \\\n     -H \"Content-Type: application/json\"\n   ```\n\n4. **Si test directo funciona, el problema está en el frontend**\n\n5. **Si test directo falla, analizar el error específico retornado**\n\n## 📊 **ENDPOINTS DE DEBUGGING DISPONIBLES**\n\n| Endpoint | Método | Propósito |\n|----------|--------|----------|\n| `/activities/:id/debug` | GET | Estado completo de debugging |\n| `/activities/:id/test-create-groups` | POST | Simula frontend, test directo |\n| `/activities/:id/algorithm/config` | GET | Configuración actual |\n| `/activities/:id/algorithm/validation` | GET | Validación completa |\n| `/activities/:id/algorithm/preview` | GET | Preview de equipos |\n| `/activities/:id/algorithm/execute` | POST | Ejecutar algoritmo (mejorado) |\n| `/activities/:id/students/questionnaires-status` | GET | Estado BELBIN detallado |\n\n## 🔧 **SOLUCIÓN INMEDIATA PARA EL USUARIO**\n\n```bash\n# 1. Obtener tu session cookie del navegador (DevTools → Application → Cookies)\n# 2. Obtener ID de la actividad de la URL\n# 3. Ejecutar test directo:\n\ncurl -X POST \"http://localhost:3000/activities/TU_ACTIVITY_ID/test-create-groups\" \\\n  -H \"Cookie: session=TU_SESSION_COOKIE\" \\\n  -H \"Content-Type: application/json\" \\\n  -v\n\n# 4. Analizar la respuesta para identificar exactamente dónde falla\n```\n\n## ✅ **VERIFICACIÓN FINAL**\n\nSi todo funciona correctamente, deberías ver:\n1. ✅ Logs detallados en la consola del servidor\n2. ✅ Respuesta exitosa del endpoint\n3. ✅ Estado de actividad cambia a 'running' → 'done'\n4. ✅ Grupos creados en la base de datos\n5. ✅ Notificación enviada al profesor\n\n---\n\n**💡 Tip:** Si el test directo funciona pero el frontend no, el problema está en la comunicación frontend-backend, no en la lógica del algoritmo.\n
